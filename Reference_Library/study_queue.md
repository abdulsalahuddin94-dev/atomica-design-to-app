# Figma study queue

Design systems with a public Figma file, waiting to be studied into the reference library with `/study-reference-ds` (one platform per session). Abdul opens one Figma link every day or two; Claude studies it and sets its row to `studied` with the date. Systems already in `references.json` are not listed.

How to use: open the link in Figma Desktop (a Community file: **Open in Figma**, which puts a copy in your drafts), then run `/study-reference-ds` with the Figma link and the GitHub link from the row. "Page" or "Profile" in the link column means the link is the kit's download page or the owner's Figma profile: find the current kit there first. Figma blocks automated link checks, so each link is checked when it is opened.

Order: mobile coverage first (our iOS and Android gaps), then systems with strong tokens and variables, active upkeep and a permissive license. License = the code's license (`code_references.json`); a Figma kit is studied read only and its look is never copied.
